# 2026-09-13

- Built Context Lab, a React/TypeScript/Vite static training app with four labs: live tokenizer and editable hypothetical costs; provider context allocation ring; retained MCP/skill context simulator with compaction and capacity guard; modular prompt builder with templates, snapshots, comparison, copy, and export. Responsive dark interface with icons, transitions, focus mode, and facilitator guide.
- No backend, credentials, analytics, remote fonts, or model API calls. Browser storage retains experiments. All model names, token rates, and capacities are explicitly illustrative; MCP retention is explained as host-dependent rather than universally permanent.
- Deployment uses vercel.json, build `npm run build`, output `dist`, Node >=22.12.0. Public npm lockfile includes cross-platform optional dependencies and was tested through a clean isolated install/build. Avoid regenerating deployment lockfiles from the shared node_modules tree, which may carry private registry resolutions and omit Linux packages.
- Validation: 15 deterministic logic tests and 60 production Chromium checks covering all labs, capacity limits, malformed storage recovery, no external resources, and 320/390/768/1440 layouts. Production preview is preferable to the hot-reload dev server for repeatable browser tests.
- `scripts/standalone.mjs` packages production assets into `outputs/context-lab.html`; portable source release is `outputs/context-lab-vercel.zip`. Main implementation files: src/App.tsx, src/PromptLab.tsx, src/logic.ts, src/ui.tsx, src/styles.css. Browser checks: tests/browser-smoke.mjs.
